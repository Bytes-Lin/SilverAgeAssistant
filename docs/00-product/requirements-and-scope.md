# 需求与范围

## 1. 角色与设备

同一 APK 安装后选择角色。角色选择不是简单主题切换，而是不同的导航图、权限和数据可见范围。

### 老人角色

默认由家属协助首次配置；老人日常不需要输入复杂账号密码。设备绑定后使用设备凭证访问 FastAPI。

### 家属角色

通过手机号或开发阶段账号登录，绑定一个或多个老人。家属不能默认查看老人完整聊天记录。

## 2. 功能优先级

### P0：第一可运行版本

- 老人端欢迎/角色页；
- 适老化首页；
- AI 对话页；
- 麦克风录音；
- ASR 请求；
- OpenAI 兼容 LLM 请求；
- TTS 请求与播放；
- Mock 与 llama-server 切换；
- 加密 API Key 设置；
- 网络失败、取消和重试。

### P1：本地实用功能

- Room 提醒；
- 服药确认和延迟提醒；
- 联系家属；
- 天气 Provider；
- 热点新闻获取、暂存与后续语音播报；
- 短期记忆和个人偏好。

### P2：家庭协同

- FastAPI 账号与绑定；
- 状态事件；
- WebSocket 在线通信；
- 断线同步；
- 家属通知与提醒指令；
- 用量监控；
- SOS 协同。

### P3：生活执行 Agent

- Tool registry；
- Policy engine；
- 无障碍节点读取；
- 模拟外卖流程；
- 一个真实 App 的有限流程；
- 订单摘要、阈值确认、家属审批。

### P4：多模态安全扩展

- 周期获取单张状态图像，不上传连续视频；
- 与聊天分离的 MLLM 结构化风险输出；
- 连续异常阈值、家属事件/短信和证据图像人工复核；
- 局域网摄像头/传感器接入预留。

### 当前跨阶段实现说明

项目没有严格串行等待每个优先级全部结束。非 Agent 部分已经完成双角色注册绑定与会话恢复、绑定失效回退、天气和新闻、真实家属联系人、通知/一次性提醒、提醒完成回传与家属记录、老人端系统通知、双端 WebSocket 提示后的 REST 自动补拉、截止后每小时本地通知、ASR/TTS Provider、远程非敏感配置以及模型用量统计。家属提醒记录清除的 Android 页面和请求映射已经完成，但中台账号级归档接口仍待交付。老人时区同步、稍后提醒重新调度、本地提醒 CRUD、周期规则、多老人管理、独立 SOS、真实摄像头接入和发布配置仍未完成。本轮不重新评估 Agent、Memory、Policy 或 GUI Agent，详见 [`../06-development/non-agent-progress-2026-08-12.md`](../06-development/non-agent-progress-2026-08-12.md) 和 [`../08-roadmap/todo.md`](../08-roadmap/todo.md)。

## 3. 质量需求

- 关键按钮触控区域不小于适老化设计要求，文案避免缩写；
- 录音、模型调用和 TTS 均可取消；
- 网络错误不删除本地任务；
- 事件上传支持重试和幂等；
- 老人端在中台或模型服务不可用时仍可查看本地提醒和拨打联系人；
- 敏感数据最小化收集；
- 所有高风险工具必须由确定性规则拦截。

## 4. Android 版本解释

“Android 10.0”定义为最低运行版本 API 29。应用仍应使用现代 compileSdk/targetSdk 编译，以兼容当前工具链和发布要求；所有 API 调用必须在 API 29 设备上测试或提供兼容分支。
