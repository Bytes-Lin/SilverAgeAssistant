# 产品总览

## 1. 产品名称

- 中文：银龄助手
- 英文：Silver Age Assistant
- 仓库：SilverAgeAssistant

## 2. 服务对象

主要服务对象是使用普通 Android 智能手机的老年人，尤其包括：

- 独居或白天缺少家人陪伴的老人；
- 不熟悉智能手机复杂操作的老人；
- 行动不便、依赖线上购物或外卖的老人；
- 需要日常服药、复诊和生活安全提醒的老人；
- 需要家属远程了解状态并给予协助的老人。

家属是第二类用户，负责初始配置、远程提醒、异常事件处理、用量查看和部分高风险操作审批。

## 3. 核心价值

1. 降低智能手机使用门槛：老人以语音表达目标，系统完成或指导操作。
2. 提供稳定陪伴：支持自然聊天、偏好记忆、日常问候和情绪安抚。
3. 改善日常执行：药物、复诊、饮食、天气、家中安全和事务提醒。
4. 加强家庭协同：向家属同步被授权的状态事件，家属可下发通知和提醒。
5. 强化安全求助：一键/语音 SOS、本地电话短信、家属协同和后续图像风险分析接口。

## 4. 产品形态

整个系统由一个 Android APK 和一个 FastAPI 中间服务组成。

- 老人模式：AI 交互与生活执行核心。
- 家属模式：配置、状态、通知、提醒和审批。
- FastAPI：两端身份、绑定、事件和指令中转。
- 云端模型：老人端使用自己的 API Key 直接调用。

## 5. 基本功能

### 老人模式

- 语音输入、文字反馈与语音播报；
- 陪伴聊天；
- Agent Tool Use；
- 日常提醒与服药确认；
- 生活助手；
- 网购、外卖辅助与金额确认；
- 快捷联系子女；
- SOS 紧急呼救；
- 跌倒风险图像上传接口；
- 热点新闻文字展示，后续接入语音播报；
- 天气、穿衣、新闻和家中安全提醒；
- 本地 API Key 管理与模型用量上报。

### 家属模式

- 创建/绑定老人档案和设备；
- 查看老人主动上报的状态事件；
- 查看提醒确认结果；
- 下发即时通知或本地提醒指令；
- 查看模型调用量和估算费用；
- 接收在线 WebSocket SOS/审批事件；
- 审批超过阈值的交易；
- 管理紧急联系人和联系优先级。

## 6. 非目标

初期不实现：

- 医疗诊断、处方调整或药物剂量决策；
- 自动填写支付密码、短信验证码或绕过生物识别；
- 可靠医疗级跌倒检测；
- 持续上传家庭监控视频；
- 支持所有外卖、电商和政务 App；
- 所有方言；
- 在无推送服务条件下承诺后台实时送达。

## 7. 成功指标

MVP 的成功不是功能数量，而是以下闭环稳定：

1. 老人能独立完成一次语音问答；
2. 老人能理解系统处于“听、想、说”的哪个阶段；
3. 本地提醒断网仍能触发；
4. 家属能看到老人上报的提醒确认状态；
5. SOS 本地电话路径不依赖服务器；
6. 高风险操作不会在未确认时继续。
