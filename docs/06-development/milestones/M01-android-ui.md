# MILESTONE 01：老人端基础 UI

## 目标

在无后端、无模型的情况下完成可导航、可测试的老人模式 UI 骨架。

## 任务

- [x] 初始化 Kotlin + Compose 工程，minSdk 29；
- [x] 建立老人/家属角色选择；
- [x] 建立适老化 Theme、Typography、Spacing、LargeActionButton；
- [x] 老人首页六个入口；
- [x] 对话页 Mock 状态机；
- [x] 对话气泡窗、Mock 问候、打字和系统手写输入入口；
- [x] 今日提醒页 Mock；
- [x] 联系家属页 Mock；
- [x] 生活助手、音乐、SOS、设置占位页；
- [x] Navigation；
- [x] 大字体和横竖屏基础测试；
- [ ] Compose screenshot/UI 测试（环境允许时）。

## 验收

- API 29 模拟器可启动；
- 老人无需阅读复杂说明即可找到语音、家属和 SOS；
- UI 不依赖网络；
- 主要按钮有语义标签；
- 没有真实 API Key 和临时硬编码业务逻辑。
