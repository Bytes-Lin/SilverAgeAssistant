# 非 Agent 功能开发进度（2026-08-12）

## 1. 核对范围

本记录只统计 Android 客户端、FastAPI 中台、端侧数据、系统能力和普通业务 UI。聊天 Agent、Tool Use、Memory、上下文压缩、GUI Agent 以及异常图像分析 Agent 不纳入本次完成度判断；它们继续以各自设计文档和开发会话为准。

“已完成”表示仓库中已有可执行代码和对应数据链路，不代表正式发布、安全审计或全部真机兼容性已经验收。

## 2. 已实现功能

### 工程、角色与身份绑定

- 单 APK 提供老人模式和家属模式，最低 Android 10（API 29）；
- 首次启动角色选择、双端基础信息表单和 Debug 测试资料回填；
- 家属注册、老人档案、一次性绑定码、家属手机号联合校验和绑定码重新生成；
- 已绑定设备重新绑定、家属 access/refresh token 与老人 device credential 加密保存；
- 应用升级或重启后的角色、登录和绑定会话恢复，普通断网不会清空本地身份。
- 中台明确返回凭证失效或绑定撤销后，两端返回身份选择页；家属登录仍有效时保留会话和既有老人档案，允许重新生成绑定码而不重复注册手机号；
- 家属初次绑定完成后导航状态立即更新，不需要重启 App 才能点击首页功能。

### 老人首页与本地信息

- 首页保留“和我说话、今日提醒、联系家人、新闻播报”四个入口；
- 日期行右侧以对号/叉号显示绑定摘要，点击后查看详细状态；
- 首页天气、最近提醒和四个入口可在普通手机屏幕内完成主要展示；
- Open-Meteo 当前天气和未来三天预报、粗略定位、真实城市反向解析及 2 小时缓存；
- 百度热搜前 15 条标题/摘要、桌面版与移动版页面解析、2 小时缓存；
- 全局语音开关开启时，新闻前 5 条附带本地日期时间进行一次 TTS 播报。

### 家属联系人与跨端通信

- 老人端通过 device credential 同步真实家属称呼、关系、电话和权限；
- 联系人快照在老人设备加密保存，离线可查看并通过系统拨号页联系；
- 家属端可发送即时通知和创建一次性提醒，中台可靠落库，老人端 REST 补拉、Room 幂等保存并发送 `STORED` ACK；
- 老人端收到 `COMMAND_AVAILABLE`、WebSocket 首次连接/重连或应用回前台时自动补拉；并发提示合并，不增加分钟级轮询；
- 即时通知只表示消息送达，不要求老人完成，也不向家属回传完成状态；
- 家属端安全事件在 WebSocket 提示、重连和回前台时自动刷新；紧急事件支持首页最新一条摘要、系统通知、缩略图、原图、弹窗 ACK 和逐条清除。

### 今日提醒闭环

- 家属端通过系统日期/时间选择器设置截止时间，禁止提交过去时刻；
- 未完成提醒写入 Room 后持续显示，不因截止时间属于未来、跨时区或已经逾期而隐藏；
- 列表按时间排序，已完成置底，“稍后提醒”和已完成使用不同样式；
- 老人点击“我已完成”后先更新 Room，再通过稳定幂等请求向中台回传；离线失败会在后续同步重试；
- 家属“提醒记录”从中台查看等待接收、待完成和已完成状态；
- 家属端收到 `REMINDER_STATUS_CHANGED`、WebSocket 重连或应用回前台时自动刷新提醒记录；
- 每条提醒记录已提供“清除”按钮；Android 仅在中台账号级归档成功后移除，避免刷新后恢复的假删除。对应中台归档接口仍待交付；
- 新家属提醒首次写入 Room 后立即显示老人端系统通知，REST 重复补拉不会重复弹出；
- 到达截止时间后，唯一 WorkManager 周期任务发送本地高优先级通知；老人仍未完成时每 1 小时重复，完成后取消；
- 应用启动扫描 Room 恢复未完成任务，WorkManager 保留跨进程退出和设备重启任务。系统省电策略可能造成延迟，因此不承诺闹钟级准点。

### 配置、语音基础与用量

- 家属端可下发非敏感文字/语音模型配置，老人端补拉、校验、原子保存并热更新；
- MLLM 与语音 API Key 只在老人设备通过 Android Keystore + AES-GCM 加密保存，不经过中台；
- 老人端全局语音开关、内存 PCM 录音、Qwen ASR/TTS WebSocket Provider、AudioFocus 和播放仲裁已接入；
- 全局 MLLM Token、ASR/TTS 次数账本、每小时批量上报、家属手动刷新、今日汇总和月度每日柱状图已实现。

## 3. 已删减或替换的功能

- “听音乐”已替换为“新闻播报”，避免测试阶段引入音乐版权和媒体授权问题；
- 老人首页“生活助手”和“紧急求助”手动入口已移除，原占位页面不计为已交付功能；独立 SOS 仍是待开发项；
- 首页功能卡片的副说明文字已移除，只保留图标和名称；
- 独立“家人绑定正常”卡片已移除，状态收纳到日期行右侧图标；
- 首页底部重复的语音按钮已移除，按住说话只在聊天页面出现；
- 家属注册不再使用开发验证密钥，也不发送 `verification_token`；
- 联系家人页不再使用测试姓名和测试号码。

## 4. 非 Agent 待开发与已知限制

- 家属提醒记录的账号级归档中台接口尚未实现；Android 已接入 `POST /elders/{elder_id}/reminders/{command_id}/archive`，接口交付前清除会显示失败并保留记录；
- 家属提醒表单当前使用家属设备系统时区。家属模拟器为 `GMT`、老人设备为 `Asia/Shanghai` 时，截止时刻会偏移 8 小时；需要由老人设备向中台同步 IANA 时区，并在家属端明确展示和使用；
- “稍后提醒”目前只是状态变化，尚未重新选择时间和重新调度；
- 老人端本地创建、编辑、删除、周期提醒、ReminderOccurrence 和执行历史尚未实现；
- 截止提醒尚未接入 TTS 播报；
- 家属普通“今日状态”的完成/清除与自然日清理规则尚未实现；
- 多老人档案切换、远程紧急联系人管理、通用 Outbox 和统一序列断线补偿尚未实现；
- 独立 SOS 倒计时、本地电话/短信/定位和中台协同尚未实现；
- 发布环境、CI、正式签名以及完整 API 29/多厂商真机验收尚未完成。

## 5. 建议的非 Agent 后续顺序

1. 交付家属提醒记录账号级归档中台接口并完成双端联调；
2. 建立老人设备时区同步，修正跨设备截止时间语义；
3. 完成“稍后提醒”重新调度、本地提醒 CRUD 和执行历史；
4. 完成家属普通状态清理、多老人切换和紧急联系人管理；
5. 开发独立 SOS 本地兜底链路；
6. 补齐发布配置、CI 和多设备验收。
