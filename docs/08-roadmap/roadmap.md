# 开发路线图

详细逐项进度见 [`todo.md`](todo.md)。路线图中的完成表示主要开发闭环已经存在，不代表安全审计或测试工作已经结束。

## M0：文档与工程初始化

- [x] 仓库结构、Codex 配置、Android/Server 工程和 Mock 数据；
- [ ] CI 与正式发布配置。

## M1：老人端基础 UI

- [x] 角色页、老人首页、对话页、提醒页、联系页和适老化基础组件；
- [x] 生活助手、音乐和 SOS 占位入口；
- [x] 家属模式首页及功能导航。

## M2：基础问答闭环

- [x] OpenAI 兼容流式文字聊天、llama-server、工具调用、错误重试和 API Key 加密；
- [x] 家属模型配置、老人端热读取及上下文用量显示；
- [ ] 录音 → ASR → MLLM → TTS → 播放闭环。

## M3：本地提醒与记忆

- [x] Room Reminder 基础、家属远程提醒落库及完成/稍后状态；
- [x] `MEMORY.md` 身份与家属长期记忆基础及 system prompt 注入；
- [ ] 本地提醒调度、执行记录、结构化短期/长期记忆、治理页面和上下文压缩。

## M4：FastAPI 双端通信

- [x] FastAPI + SQLite 家属注册、老人档案、绑定码、设备凭证和会话恢复；
- [x] 家属通知/提醒、联系人同步、模型配置、模型用量、安全事件和 WebSocket 在线提示；
- [x] 家属今日状态、紧急事件、用量图表和状态检测设置；
- [ ] 通用 Outbox、统一序列断线补偿、多老人管理、提醒结果回传和审批事件。

## M5：SOS 与联系

- [x] Agent 家属电话工具和状态监控异常短信；
- [ ] 独立 SOS 倒计时、本地电话/短信/定位、FastAPI SOS 事件和家属确认。
