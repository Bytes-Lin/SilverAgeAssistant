# 开发路线图

## M0：文档与工程初始化

- 仓库结构；
- Codex 配置；
- Android/Server 工程；
- CI 基础；
- Mock 数据。

## M1：老人端基础 UI

角色页、老人首页、对话页、提醒页、联系页、生活助手占位、音乐页、SOS 页、设置页。

## M2：基础问答闭环

录音 → ASR → LLM → TTS → 播放；本地 llama-server/Mock 可切换；API Key 加密。

## M3：本地提醒与记忆

Room、提醒调度、执行记录、短期记忆、偏好记忆、上下文压缩。

## M4：FastAPI 双端通信

已启动。首版采用单进程 FastAPI + SQLite；家属注册、老人档案、一次性绑定码、设备凭证和绑定查询已实现，Android 联调以及 REST 事件、WebSocket、断线补偿、远程提醒和用量上报待后续任务完成。当前不引入 PostgreSQL、Redis 或数据库 Docker 基础设施。

## M5：SOS 与联系

本地电话/短信/定位、FastAPI 紧急事件、家属确认、离线和权限失败测试。

## M6：基础生活工具

本地音乐、天气、新闻、电话、消息和生活安全提醒。

## M7：Agent Tool Use

工具注册、Policy Engine、任务状态机、RAG、记忆治理、审计。

## M8：无障碍生活助手

模拟外卖 App → 一个真实 App 的有限流程 → 订单摘要 → 阈值确认 → 家属审批。

## M9：图像风险接口

图像选择、压缩、MLLM JSON 输出、人工复核 UI，不实现持续监控。

## M10：稳定性与试点

API 29 真机矩阵、适老测试、安全审计、成本监控、崩溃与离线恢复。
