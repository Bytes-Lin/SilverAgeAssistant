## 建议的下一开发顺序

1. 完成记忆治理基础：结构化 MemoryItem、写入确认、检索和管理页；
2. 接入上下文预算与压缩，使长对话具备可控的跨会话上下文；
3. 建立 GUI Agent 的 Policy Engine、任务状态机和 Accessibility 观察/执行接口；
4. 使用模拟外卖 App 跑通“搜索 → 候选 → 摘要 → 老人确认”，暂不接支付；
5. 再接入家属审批和一个真实 App 的有限白名单流程；
6. GUI 流程稳定后补齐 ASR/TTS，进行完整语音驱动验证。
