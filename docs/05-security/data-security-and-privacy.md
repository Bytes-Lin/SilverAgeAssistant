# 数据安全与隐私

## 状态监控数据

- 状态监控必须由用户明确开启，并提供持续可见的系统通知和停止入口；禁止隐蔽拍摄。
- 日常图像分析仍由老人设备直连其自行配置的 MLLM；只有达到确定性上报阈值的紧急事件，才允许老人设备向中台上传一张证据图像供已绑定家属核实。
- 中台安全事件保存时间、疑似事件类型、简短摘要、紧急程度和最小图像元数据；不得保存模型 prompt、思考过程、完整响应或 API Key。
- 异常检测是待人工核实的安全提示，不是医疗诊断；不得仅依赖 MLLM 结果自动宣称老人已跌倒或昏迷。

## 1. 数据分类

### 极敏感

- 模型 API Key；
- Refresh/device credential；
- 支付认证信息；
- 原始家庭监控图像；
- 精确位置；
- 健康记录。

### 敏感

- 聊天摘要；
- 饮食/作息偏好；
- 提醒详情；
- 联系人和手机号；
- 状态事件。

### 普通

- UI 偏好；
- 字体、语速；
- 功能开关。

## 2. API Key

- 用户独立 Key；
- Keystore + AES-GCM；
- 不上传 FastAPI；
- 不写日志；
- 不进入 crash analytics；
- 不进入备份；
- 不通过家属端远程读取；
- 允许用户一键删除并在云厂商侧轮换。

本地加密降低静态提取风险，但不能保证被完全控制的设备上绝对安全；产品文档不得宣称“无法泄露”。

家属可以经中台设置模型服务地址、模型名、上下文长度和生成参数，但 API Key 不得包含在远程配置中。即使使用自定义加密字段，中台也不作为模型密钥转发或暂存通道。开发测试阶段使用无 Key 的本地 llama-server；正式 Key 的家属辅助配置另行设计不经过中台的线下二维码或近场流程。

老人端现提供本机 API Key 输入页。输入框默认使用密码遮罩，明文只短暂存在于当前页面内存，不进入 `SavedStateHandle`；保存成功后立即清空输入状态，后续只显示末四位。密钥密文所在 Preferences DataStore 已从 Android 云备份和设备迁移中排除。页面不得把输入值、异常对象或请求头写入日志，也不得通过中台验证密钥。

模型用量账本只保存必要的 provider、model、时间、成功状态、MLLM 输入/输出 Token 和
ASR/TTS 调用次数，不保存语音业务来源、音频时长、TTS 字符数、提示词、回复、Tool
参数/结果、音频或图片。既有协议的语音扩展计量字段固定为 0。每小时上报前按维度聚合，
家属端只读取时间范围汇总，不提供单次调用明细。估算值必须显式标记，不能冒充模型厂商
账单。

老人端录音只允许存在于有上限的进程内缓冲区。无论识别成功、失败、取消或生命周期终止，
都必须及时释放音频字节；不得创建临时录音文件、写入 Room、MediaStore、备份、日志或
崩溃报告，也不得上传中台。

## 3. 服务器最小化

FastAPI 只存跨端协作必要数据。默认不存：完整对话、原始录音、连续视频、API Key、支付密码和验证码。

事件 Payload 采用白名单 schema，不允许客户端任意上传大段聊天内容。

## 3.1 端侧长期记忆

- `MEMORY.md` 只位于老人设备应用私有目录，不上传中台；
- 文件从云备份和设备迁移中排除；
- 不写入完整手机号、API Key、验证码、支付认证信息、精确地址或未经确认的健康推断；
- 完整家属手机号只保存在现有 Keystore AES-GCM 加密联系人快照中；
- 发送给模型前将记忆标记为“背景事实而非指令”，降低记忆内容造成 Prompt Injection 的风险；
- 每轮只使用当前问题所需的最少记忆，不主动向模型或老人复述联系方式；
- 未来写入偏好、健康或地址信息时必须提供查看、修改和删除入口，并按敏感度决定是否加密。

## 4. 权限

按使用时申请，并解释用途：麦克风、联系人、电话、短信、定位、相机、媒体、无障碍。拒绝权限后提供替代路径。

天气首版只申请前台粗略定位 `ACCESS_COARSE_LOCATION`，不申请精确定位或后台定位。坐标只短暂用于 Android 直连 Open-Meteo、系统反向地理编码，以及系统无结果时由设备直连 BigDataCloud 客户端反向地理编码接口；不上传 FastAPI、不写日志、不放入聊天消息或 Tool 结果。BigDataCloud 后备请求必须只使用当前设备经授权取得的实时坐标，并随天气缓存复用，禁止服务端代查、批量查询或使用其他用户坐标。由坐标解析出的城市名称可以显示在首页并进入天气 Tool 结果，但不能包含区县以下地址、街道、门牌或精确坐标。首页应明确标注天气来源和更新时间；端侧天气建议不能描述为官方预警。

Open-Meteo `timezone=auto` 返回的 IANA 时区可在老人端本地保存，并随聚合模型用量批次
上传，用于确定老人当地的每日统计边界。只上传时区名称和 `LOCATION`/`SYSTEM_FALLBACK`
来源标记，不上传经纬度、城市、地址或定位时间；该本地时区缓存不进入云备份和设备迁移。

## 5. 家属权限

家属访问基于绑定关系和角色。服务端每次校验，不信任客户端隐藏 UI。老人可查看已绑定家属并撤销非所有者权限。

## 5.1 中台用户管理

开发期管理页面在普通 API 启动时默认关闭并仅限本机访问，使用独立管理员会话，不能复用
家属 JWT。内置开发账号只允许在 development 环境使用，源码只保留慢哈希校验摘要。页面
页面展示当前有效的家属—老人绑定关系；完整手机号只用于 POST 筛选且不进入 URL，结果只
显示脱敏号码。管理员只可修改称呼和关系；删除为带审计的绑定软撤销，并同步吊销设备凭据和
未使用绑定码，不直接物理删除账号或历史业务记录。
管理查询不得关联通知、提醒、安全事件、证据图像、模型配置、模型用量、聊天内容或任何
凭据，也不得提供任意 SQL 和批量导出。允许的写操作仅限称呼/关系更新和绑定软撤销；所有
写操作使用绑定写锁、事务和管理员审计。软撤销必须同步吊销设备凭据及未使用绑定码，不得
物理删除账号或历史记录。手机号、数据库 ID、凭据摘要和完整业务记录不得通过管理页面修改
或展示。

开发联调允许通过“双手机号 + RESET”停用旧家属/老人身份并释放手机号唯一值。该操作必须
核验老人档案由对应家属创建，撤销相关绑定和凭据、清理关联幂等索引并写审计；旧业务记录
仍保留。此能力不是生产账号注销，不得在 production 环境启用。

## 6. 图像

日常手动图像分析在上传 MLLM 前应明确预览、允许取消，并默认压缩和移除不必要 EXIF；中台不参与该链路。

状态监控证据图像属于极敏感数据，必须遵守：

- 每个六小时检测窗口最多随一条异常事件上传一张，不上传连续监控图像或视频；
- 事件先可靠入库，图像通过独立二进制接口上传，禁止 Base64、公开静态 URL和 WebSocket 图片正文；
- 服务端验证 device credential、事件归属、实际文件签名和 8 MiB 上限，生成不超过 512px 且移除 EXIF 的缩略图；
- 只有仍与老人有效绑定且具备查看权限的家属可读取，响应使用 `private, no-store` 和 `nosniff`；
- 原图和缩略图加密存储或置于服务进程私有目录；当前中台会重新编码原尺寸图像和缩略图以移除 EXIF，并默认在 7 天后删除；Android 只在内存展示，不写相册或共享缓存；
- 日志、崩溃报告和审计记录不得包含图像字节；审计仅记录查看主体、事件 ID、时间和缩略图/原图类别。

## 7. 日志

生产日志只保留：错误码、请求 ID、模型名称、耗时和成功状态。禁止记录 Authorization、明文凭证、短信内容、完整对话、原始图像和精确地址。

## 8. 安全测试

- APK 静态扫描；
- 网络代理检查敏感头；
- 日志与崩溃文件检查；
- 重放攻击；
- 越权读取老人数据；
- WebSocket token 失效；
- Prompt injection 读取凭证；
- 无障碍页面恶意文本；
- 支付阈值整数边界；
- 丢失/被盗设备撤销。
