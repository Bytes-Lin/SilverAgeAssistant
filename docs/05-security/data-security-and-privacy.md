# 数据安全与隐私

## 1. 数据分类

### 极敏感

- 模型 API Key；
- Refresh/device credential；
- 支付认证信息；
- 原始家庭监控图像；
- 精确位置；
- 健康记录。

### 敏感

- 聊天摘要；
- 饮食/作息偏好；
- 提醒详情；
- 联系人和手机号；
- 状态事件。

### 普通

- UI 偏好；
- 字体、语速；
- 功能开关。

## 2. API Key

- 用户独立 Key；
- Keystore + AES-GCM；
- 不上传 FastAPI；
- 不写日志；
- 不进入 crash analytics；
- 不进入备份；
- 不通过家属端远程读取；
- 允许用户一键删除并在云厂商侧轮换。

本地加密降低静态提取风险，但不能保证被完全控制的设备上绝对安全；产品文档不得宣称“无法泄露”。

## 3. 服务器最小化

FastAPI 只存跨端协作必要数据。默认不存：完整对话、原始录音、连续视频、API Key、支付密码和验证码。

事件 Payload 采用白名单 schema，不允许客户端任意上传大段聊天内容。

## 4. 权限

按使用时申请，并解释用途：麦克风、联系人、电话、短信、定位、相机、媒体、无障碍。拒绝权限后提供替代路径。

## 5. 家属权限

家属访问基于绑定关系和角色。服务端每次校验，不信任客户端隐藏 UI。老人可查看已绑定家属并撤销非所有者权限。

## 6. 图像

图像上传前：

- 明确显示将上传的图片；
- 允许取消；
- 默认压缩并移除不必要 EXIF；
- 不在 FastAPI 中转/保存；
- 云端调用完成后本地按用户选择保留或删除；
- 返回结果标注不确定性。

## 7. 日志

生产日志只保留：错误码、请求 ID、模型名称、耗时和成功状态。禁止记录 Authorization、明文凭证、短信内容、完整对话、原始图像和精确地址。

## 8. 安全测试

- APK 静态扫描；
- 网络代理检查敏感头；
- 日志与崩溃文件检查；
- 重放攻击；
- 越权读取老人数据；
- WebSocket token 失效；
- Prompt injection 读取凭证；
- 无障碍页面恶意文本；
- 支付阈值整数边界；
- 丢失/被盗设备撤销。
