# 风险登记

| 风险 | 影响 | 当前缓解措施 |
|---|---|---|
| 无推送服务时后台消息不实时 | 家属错过即时状态 | WebSocket 前台 + REST 补拉 + 显示最后更新时间；SOS 本地兜底 |
| 本地用户 API Key 被逆向/运行时获取 | 用户账号费用损失 | 每人独立 Key、Keystore 加密、日志屏蔽、额度告警、可删除/轮换 |
| ASR 误识别金额、联系人或求救 | 错误操作 | 低置信度确认、高风险复述、取消窗口 |
| 无障碍页面变化 | 自动操作失败 | 节点语义、页面验证、有限支持矩阵、失败即停止 |
| LLM Prompt injection | 泄密或危险工具调用 | Tool allowlist、Policy Engine、凭证不进入上下文 |
| 家属把“确认”当作事实 | 健康误判 | UI 使用“已确认/未确认”，不作实际行为结论 |
| 跌倒图像误报/漏报 | 延误或误报警 | 仅初步分析接口、人工复核、不自动急救 |
| Android 后台限制 | WebSocket/任务停止 | 本地提醒、WorkManager 补偿、明确非实时状态 |
| 老人不会配置 API Key | 上手困难 | 家属面对面协助、扫码/粘贴、验证和简单错误文案 |
| 模型费用不透明 | 家属成本担忧 | 本地用量估算、阈值、模型选择、云账户预算告警 |
| 医疗建议越界 | 健康风险 | 不诊断、不改剂量、危险症状引导联系专业人员/急救 |
| 隐私过度共享 | 老人不信任 | 最小化事件、默认不共享聊天原文、可撤销绑定 |
