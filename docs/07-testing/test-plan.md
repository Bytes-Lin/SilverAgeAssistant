- TTS 失败；

- 大字号下不截断关键按钮；

- 打字发送后清空草稿、立即追加老人字符串并逐段展示模型回复；

- 完成绑定、恢复既有老人会话和同步联系人后更新设备私有 `MEMORY.md`；

- `MEMORY.md` 不进入 Android 云备份或设备迁移。

- `model-config.json` 不进入 Android 云备份或设备迁移。

- `get_weather` 结果包含缓存状态但不包含经纬度，权限或服务失败返回结构化错误；
- WMO 天气码、温度、降雨概率和恶劣天气行动建议映射正确，未知天气码不导致崩溃；
- 应用不申请精确定位和后台定位，坐标不进入中台、模型上下文、日志或备份；
- 天气卡标注“天气数据：Open-Meteo”，生活建议不冒充官方灾害预警。

## 6. Agent 与购物

- GUI Tool 创建任务后立即返回 `todo_id`，不得等待 GUI Run 完成或阻塞主聊天；
- 同一设备存在非终态 GUI 任务时，第二个任务返回忙碌且不能取得屏幕控制权；
- 第一次完整 GuiRun 失败后只告知老人并自动开始第二次，不创建家属事件；
- 第二次完整 GuiRun 失败后只调用一次家属协助出口，相同 Todo 重试不能重复通知；
- ReAct 单步失败、重规划、老人修改需求、暂停、离开目标 App、语音输入和进程中断均不
  增加完整失败次数；
- Executor 在每个真实动作前检查控制门，暂停后不产生新动作，取消后排队动作全部失效；
- 新进程把遗留 `RUNNING/PAUSED` Todo 转为 `INTERRUPTED`，只提示重新开始，不恢复
  节点、截图或动作序列；
- Todo 数据库只包含任务内容和状态元数据，不包含候选商品、地址、手机号、订单号、页面
  内容、截图、ReAct 历史或支付信息；
- 主聊天和 GUI Agent 的 Registry 引用同一个 `get_current_time` Tool 实例，GUI Registry
  不包含尚未确认共享的其他 Tool；
- 主聊天模型用量归入 `conversation`，GUI Agent 用量归入 `gui_agent`，上下文和记忆
  不能跨 Agent 累计；
- ASR/TTS 未接入时共享 Provider 明确返回不可用，按住说话入口不得伪造识别或播报成功；
- 主 Agent 的工具列表包含 `gui_agent`，打开或操作美团、微信、淘宝的单一及复合指令均返回
  Todo 且不阻塞聊天；主 Agent 不得把 `STARTED` 扩写成页面结果；
- 纯打开任务只有无障碍观察确认目标包在前台后才完成，包含点击/下单的任务必须经过逐帧观察和结果验证，
  不能把 Tool 的 `STARTED` 或单个动作成功伪造成完整任务完成；
- 非纯打开任务在零真实动作或缺少动作后新截图时返回 `complete` 必须被执行器拒绝；
- 目标 App 会话未建立时不显示跨 App 悬浮控制条；启动失败不能短暂悬浮后伪报成功；
- 等待态暂停再继续时恢复原 `WAITING_*` 阶段，而不是错误重置为普通运行；
- 顶部控制条在运行态显示“暂停”，离开目标 App 后显示“返回任务”，取消必须二次确认；
- 无障碍服务未启用时不绕过系统授权；启用后控制条可覆盖目标 App，明确触摸或宽限期外点击
  映射为 `HUMAN_INTERVENTION`；Agent 点击后的延迟事件、自动滚动、同包 Activity/页面跳转
  不得暂停；非目标过渡窗口恢复目标包时不得暂停，持续离开目标包才映射为
  `TARGET_APP_LEFT`；
- 银龄助手自身窗口和控制条事件不得被误判为目标 App 人工操作；
- 当前能力不支持或目标 App 未安装时进入 `UNAVAILABLE`，不自动重试两次、不通知家属；
- 1440×3200 等高分辨率截图同时受最长边和总像素预算限制，resize 只缩小不放大；
- 裁剪后的截图 resize 能使用精确实际输出尺寸反向映射，不能使用整数近似比例；
- 模型 `0..1000` 归一化坐标经过逆 resize、逆裁剪和截图到屏幕变换后落在正确手势像素；
- Accessibility 截图为 `1200×2664` 而资源可用区域为 `1200×2413` 等带系统栏设备上，手势
  坐标必须使用真实物理显示尺寸；不得按可用区域高度压缩纵坐标，Debug 中同尺寸截图的
  `captureToScreen` 应为 `1.0,1.0`；
- MediaProjection 输出尺寸与屏幕尺寸不同时，坐标映射包含系统等比缩放和居中偏移；
- 模型像素坐标回显的图像宽高与实际上传图像不一致时拒绝动作；
- 旧 `frame_id`、旋转后帧、窗口切换后帧、人工触摸前帧和不属于当前显示的帧均拒绝；
- 反向映射落在图片补边、目标窗口外、屏幕外或顶部控制条区域时拒绝；
- 每个真实动作前重新截图；同一截图不能连续驱动两个未经重新观察验证的动作；
- 动态页面在 MLLM 推理期间改变节点树路径时，`click_node` 必须先按稳定语义重匹配；仅在
  当前同语义节点存在但拒绝 `ACTION_CLICK` 时允许按实时节点中心手势降级，完全无法匹配时
  必须拒绝旧坐标；支付、提交订单、密码和验证码节点在三条点击路径中均不得绕过策略；
- Debug 纯坐标模式的 MLLM payload 不得包含 `accessibility_nodes`，模型返回 `click_node`、
  `node_id` 或带节点的滚动/输入必须被解析器拒绝；`click_point` 必须经过完整逆 resize 坐标
  映射，文本只能写入此前由坐标点击获得焦点的普通输入框；切换回节点优先后原节点路径、
  语义重匹配与坐标降级能力保持不变；Release 不得开启纯坐标实验；
- GUI ReAct 每个完整 Run 最多 20 步，连续 3 次规划/动作失败后结束本 Run，不与两次完整
  Run 重试预算混淆；
- GUI MLLM 必须复用模型配置的连接/读取超时，响应耗时超过 10 秒但未超过配置读取超时时
  不得被 OkHttp 默认超时提前终止；
- 节点树存在目标时优先节点 Action，模型坐标不能强制绕过不可点击节点或 Policy；
- 顶部 Accessibility 悬浮条不进入发给模型的目标窗口截图；API 30—33 兼容路径单独验证；
- 原图、resize 图、模型坐标和页面文本不进入 Room、中台、日志、备份或长期记忆；
- 支付、密码、验证码、生物识别和安全窗口拒绝截图及 MLLM 操作；
- “提交订单”只有老人完成 `ORDER_SUBMISSION` 确认门后才获得一次性动作授权；“去支付/
  立即支付/确认支付”即使模型要求也始终拒绝；
- 模型幻觉工具名；
- 金额小于、等于、大于阈值；
- 价格在确认后改变；
- 地址改变；
- 多商品总价；
- ASR 把 15 识别为 50；
- 家属拒绝/超时；
- 支付页包含恶意提示；
- 无障碍节点缺失；
- 页面版本变化；
- App 进入后台后任务恢复。

## 7. 图像分析

状态监控基础组件覆盖：默认 5 分钟、1..60 分钟边界、revision 冲突、断网保留上次配置、WebSocket 丢失后 REST 补拉、事件幂等、一般/紧急分类、跨时区今日边界、未 ACK 紧急事件恢复弹窗，以及证据图像的独立上传和授权读取。中台须补充图像接口、权限、保留期和第二次 WebSocket 提示测试；Android 离线与弹窗恢复仍需端到端验证。

- `enabled` 缺失或不是 JSON 布尔值时返回 `INVALID_SAFETY_ENABLED`，不能接受字符串或数字替代；
- `enabled=false` 与合法的非零间隔共同持久化，双方 GET 必须返回该字段；
- 仅改变 `enabled` 也会递增 revision、改变幂等指纹并发送配置可用提示；
- 迁移前已有配置升级后为 `enabled=true`，不得意外关闭老人端监控；

- 默认开启后启动带常驻通知的独立前台服务，老人端不显示停止入口；家属关闭后停止服务并清空六小时暂存历史；
- 运行中从 1 分钟改为 5 分钟会取消旧等待并按 5 分钟重排，已有历史、连续异常次数和短信标记保持不变；快速连续下发配置最终应用最新 revision；
- WebSocket 断线后恢复连接并由 REST 补拉完整配置；服务进程由 `START_STICKY` 恢复时读取最后一次本地配置；
- mock 图像按稳定顺序轮换，图像 MIME 类型正确；正式 `NetworkCameraImageSource` 不影响 Agent 编排；
- MLLM 请求包含独立 system prompt、最近一次状态 context、设备 UTC 时间、单张图像和严格 JSON 要求，不包含聊天历史、手机号或 API Key 正文；
- 正常结果允许省略详情，异常结果缺少详情、未知状态、多余字段、Markdown 外文本和超大图像均拒绝；
- 正常结果将连续异常次数归零；第 1 次异常不通知，第 2 次创建本窗口唯一事件并上传触发图像，第 3 次仅发送一次短信；同一六小时窗口后续异常不再创建事件或重复短信；
- 六小时窗口到期自动清空；修改间隔不清空；关闭后重新开启从空窗口开始；
- 短信只发给本机加密快照中的紧急联系人并去重，未授权 `SEND_SMS`、无联系人或发送失败时不得标记成功；
- 状态监控模型调用记入全局 MLLM 用量，feature 为 `safety_monitoring`；除本窗口唯一事件的单张证据图像外，其他图像、完整模型响应和检测历史不上传中台或进入备份；
- 图像 PUT 验证 JPEG/PNG 实际签名、8 MiB 上限、事件归属和幂等冲突；生成去 EXIF、最长边不超过 512px 的缩略图；

## 9. 模型用量

- OpenAI 流式响应含完整 usage 时记录精确 input/output Token；
- llama-server 不返回 usage 时生成估算值并显示估算标记；
- Tool Use 产生多轮模型请求时逐轮累计；
- 取消、超时和失败调用记录失败次数，不保存聊天正文；
- 上下文圆形进度不小于 0、不超过 100%，无 usage 时保持可理解状态；
- 家属下发新的 `context_window_tokens` 后，老人补拉并在下一轮聊天使用新值作为圆形进度分母；旧配置缺失字段时使用 32768；
- Room 1→2 迁移保留既有提醒；
- 每小时任务尝试上传，成功后标记，失败后保留并交给 WorkManager 退避重试；VPN、私有网络和 Android“部分连接”状态不得让任务永久卡在 `CONNECTED` 约束；
- 家属只进入用量页面或页面自动重组时仅查询中台，不触发老人设备即时上传；
- 家属点击“立即刷新用量”后，中台向在线老人设备发送一次 WebSocket 事件，老人端的一次性任务上传尚未汇报记录，家属端在约 6 秒内显示更新后的汇总；
- 相同刷新请求幂等重试返回首次时间和在线结果，不重复投递；同一家属对同一老人 3 秒内的新刷新请求被限流；
- 刷新事件只投递给仍有效的 device credential 连接，事件只包含协议字段和 `client_request_id`；
- 老人设备离线时，手动刷新保留中台上次汇报值并显示离线说明；不得将 `last_reported_at: null` 渲染为字符串 `null`；
- 小时任务和即时任务并发时串行上传，相同本地批次不会重复累计；
- 相同 batch 幂等重试不重复累计；
- 相同 batch 改变请求体返回幂等冲突，101 个 items 返回批次过大；
- 中台从 device credential 推导老人和设备，不接受请求体覆盖身份；
- 用量批次拒绝非法 IANA 时区和未知来源；最近 `LOCATION` 时区优先且不被后续 `SYSTEM_FALLBACK` 覆盖；
- 每日接口按老人当地当前自然月返回升序完整日期，月初、月末和零用量日期边界正确；
- 每日桶按批次 `period_started_at` 的老人当地日期归属，Token 和三种模态计量规则与汇总接口一致；
- 尚无位置时区时响应明确返回 `SYSTEM_FALLBACK`，异地家属不能通过查询参数覆盖老人时区；
- 上报周期必须为 UTC、正序、不超过 7 天且未来容差不超过 10 分钟；家属查询不超过 366 天；
- MLLM Token、三种模态调用次数、ASR 时长和 TTS 字符/时长按模态正确聚合，任一估算项使汇总标记为 true；
- 无数据查询返回全 0 totals 和空最后上报时间，不返回 404；
- 家属只能查询有效绑定老人，页面明确标注客户端统计而非厂商账单；
- 老人位置天气成功后保存 Open-Meteo `timezone=auto` 返回的 IANA 时区并随用量批次上报，不根据城市名猜测或硬编码上海；
- 中台优先使用老人最近的 `LOCATION` 时区返回当地 `current_date` 和每日分桶；家属请求不包含时区参数，空日期为 0；
- 尚无位置时区时 `SYSTEM_FALLBACK` 必须透传到家属页面并显示提示，且不能覆盖已有的位置时区；
- 家属端今日卡片只读取当天桶；Token 图按天区分输入/输出，语音图按天区分 ASR/TTS，横向滚动和无障碍描述可用；
- 每日接口不可用时仍展示月汇总和兼容提示，Android 不退化为逐日发起三十多次请求；
- ASR/TTS Provider 接入后分别验证调用次数，且请求 schema、数据库和审计均不上传 API Key、提示词、音频或文本。

## 10. 中台用户管理

- 普通 `app.main` 启动时 `/admin` 返回 404，管理启动器只在 development 环境启用管理功能；
- `admin` 和 `test` 均可登录且权限一致，错误账号或密码不能建立会话；
- 管理会话 Cookie 使用 HttpOnly、SameSite=Strict，退出和服务重启后失效；
- 外部来源访问 `/admin` 返回 404，即使业务服务监听 `0.0.0.0`；
- 登录后默认展示全部有效家属—老人绑定对，已撤销绑定不展示；
- 页面只显示双方称呼、脱敏手机号、关系、账号状态、有效设备数和绑定时间；
- 完整手机号筛选使用 POST，不进入 URL、Referer 或响应；SQL 通配符不能枚举账号；
- 页面和表单不暴露 family、elder、binding 数据库 ID、JWT、device credential 或摘要；
- 修改双方称呼和关系后事务提交、页面回显且写入管理员审计；非法关系和越界称呼被拒绝；
- 撤销绑定必须提交 `DELETE` 确认，并原子撤销绑定、设备凭据及未使用绑定码；
- 撤销后旧 device credential 立即认证失败，账号和历史业务记录仍保留；
- 仅撤销绑定后原手机号仍被旧账号占用；执行“双手机号 + RESET”后旧身份停用、原手机号可
  重新注册和创建老人档案，且旧设备凭据继续无效；
- 联调账号重置拒绝不匹配的家属—老人组合，不物理删除旧业务历史，并写管理员重置审计；
- 启动器接受自定义有效 IP 和 1—65535 端口，默认不打开浏览器，仅在指定
  `--open-browser` 时打开正确管理 URL。
