# 测试计划

## 1. 测试层级

- Domain 单元测试；
- Repository/Provider 集成测试；
- Compose UI 测试；
- Android API 29 真机/模拟器测试；
- FastAPI 路由、服务和 WebSocket 测试；
- 端到端双设备测试；
- 安全与可用性测试。

## 2. 第一阶段语音问答

- API Key 未配置；
- Key 验证失败；
- 麦克风拒绝；
- 录音取消；
- ASR 超时/空文本；
- LLM 流式中断；
- TTS 失败；
- AI 播放时再次录音；
- 网络切换；
- 屏幕旋转/进程重建；
- 大字号下不截断关键按钮。

## 3. 提醒

- 设备重启后恢复；
- 时区变化；
- 夏令时（如适用）；
- 同一提醒重复触发；
- 稍后提醒；
- 未确认上报；
- 离线 outbox；
- 家属指令重复下发。

## 4. 通信

- WebSocket 断线重连；
- REST 补拉无重复；
- ACK 丢失；
- 事件乱序；
- Token 过期；
- 家属越权；
- 一老人多家属；
- 一家属多老人；
- 对端 App 被杀后的最后更新时间显示。

## 5. SOS

- 无网络；
- FastAPI 超时；
- 无定位权限；
- 无短信权限；
- 拨号权限拒绝；
- 取消倒计时；
- 连续触发；
- 老人误触；
- 本地拨号是否与网络请求并行；
- 家属端未在线时系统是否错误宣称“已通知”。

## 6. Agent 与购物

- 模型幻觉工具名；
- 金额小于、等于、大于阈值；
- 价格在确认后改变；
- 地址改变；
- 多商品总价；
- ASR 把 15 识别为 50；
- 家属拒绝/超时；
- 支付页包含恶意提示；
- 无障碍节点缺失；
- 页面版本变化；
- App 进入后台后任务恢复。

## 7. 图像分析

- 无人物；
- 多人；
- 图片过大；
- 模糊/暗光；
- 模型非 JSON 输出；
- 高风险误报；
- API 失败；
- 图像元数据清理；
- 结果不应自动触发急救。

## 8. 适老化可用性

邀请真实目标用户或代理测试：

- 能否独立找到语音按钮；
- 是否理解当前状态；
- 是否能停止 AI 说话；
- 是否理解订单确认；
- 是否知道 SOS 已执行哪些动作；
- 错误后是否知道下一步；
- 家属设置是否能降低老人操作量。
