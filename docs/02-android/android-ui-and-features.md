# Android UI 与功能说明

## 1. 设计原则

- 大按钮、大字号、高对比；
- 首页固定，避免动态信息流；
- 一屏只强调一个主要任务；
- 语音为主，按钮兜底；
- 每一步都说明“正在听、正在处理、正在播放”；
- 错误文案告诉老人下一步怎么做；
- 涉及金额、药物、身份和求救时必须复述确认。

## 2. 角色入口

首次启动：

- “给老人使用”
- “我是家属”

家属可通过绑定码协助老人配置。老人模式可设置为默认启动角色，避免每次选择。

当前初始化 UI 流程：

```text
角色选择
├── 给老人使用 → 老人基础信息 → 老人首页
└── 我是家属   → 家属基础信息 → 家属首页
```

- 老人基础信息包含称呼、可选的家属手机号、6 位绑定码和状态摘要共享确认；手机号与绑定码必须一起填写，没有绑定资料时允许先进入老人模式。
- 家属基础信息包含家属称呼、家属手机号、老人称呼、老人手机号、关系和紧急联系人选择；关系不提供“配偶”选项。
- Android 已接入家属直接注册、老人档案、一次性绑定码和老人设备绑定接口；注册请求只提交称呼、手机号和幂等 UUID，不再调用开发验证令牌接口。请求失败时停留在表单，只有收到服务端成功响应后才显示“绑定码已生成”或“已绑定”。
- 家属端注册与生成绑定码、老人端手机号和绑定码联合校验均已在本地模拟器完成中台在线联通验证。
- Debug 构建通过 Repository + Preferences DataStore 临时保存双方称呼、手机号、关系、紧急联系人选项和共享确认，便于重复测试；Release 构建禁用该测试持久化。
- 测试 DataStore 从云备份和设备迁移中排除，不保存绑定码、验证码、access/refresh token 或 device credential。
- access/refresh token 和 device credential 使用 Android Keystore AES-GCM 密钥加密后写入独立私有存储，并排除云备份与设备迁移；绑定码只保留在当前进程状态中。
- 正式应用状态使用独立的 Preferences DataStore 保存默认角色、双方初始化完成标记、最后已知绑定状态和最后同步时间；该状态在 Debug 与 Release 构建中均启用，不保存手机号或任何认证凭证。
- 应用启动时先读取正式应用状态和加密凭证：已完成初始化且凭证存在时直接进入对应首页，不再回到注册表单。升级前已安装版本若只有加密凭证，会在首次启动时推断并迁移角色和完成状态。
- 进入首页后通过 `GET /api/v1/bindings` 后台校验会话。家属 access token 失效时先调用 `/api/v1/auth/refresh`，保存新 token 后重试；离线时保留本地首页并显示离线状态，服务端明确判定凭证无效时清除对应凭证并显示“登录已失效”。

## 3. 老人首页

固定六个主要入口：

1. 和我说话
2. 今日提醒
3. 生活助手
4. 联系家人
5. 听音乐
6. 紧急求助

顶部显示日期、天气摘要和最近一条重要提醒；底部始终显示大号语音按钮。

### M01 UI 骨架实现说明

- 首次安装先进入老人/家属角色选择页；已经完成初始化并保存有效凭证时，后续启动直接进入相应首页。
- 老人首页使用响应式两列/三列网格，主要按钮最小高度为 72dp，并为语音、联系家人、紧急求助和设置提供语义标签。
- 首页天气显示“暂未更新”，避免在没有网络数据时展示虚假天气；提醒摘要使用 M01 Mock 数据。
- 底部语音按钮固定可见，点击进入对话 Mock 状态机，不申请麦克风权限、不录音、不访问网络。
- 生活助手、音乐、SOS 和设置页均为不可执行的占位页；SOS 页明确提示当前阶段不会拨号，并引导真实紧急情况直接拨打 120。

## 4. AI 对话页

状态机：`Idle → Listening → Transcribing → Thinking → Speaking → Idle`。

页面元素：

- 当前状态大字；
- 老人识别文本；
- AI 回复大字；
- 开始/结束录音；
- 停止播放；
- 重播；
- 取消任务。

ASR 置信度低或识别出高风险意图时先复述确认。

## 5. 生活助手

语音入口接收目标，例如：

- “打开外卖软件，我想吃面。”
- “帮我买一袋大米。”
- “查一下快递到哪里了。”
- “帮我打车去医院。”

流程：理解意图 → 获取偏好与约束 → 推荐选项 → 老人选择 → 无障碍执行 → 订单摘要 → 金额确认 → 第三方支付。

推荐依据只使用已确认偏好、预算、配送时间、忌口和历史选择。不得根据未经确认的疾病推断医疗饮食。

## 6. 网购/外卖支付规则

- 所有付费订单在提交支付前至少一次明确确认；
- 超过本地配置阈值需要二次确认或家属审批；
- 商品、数量、价格、地址变化后旧确认失效；
- 摘要必须包含商家、商品、数量、地址、总额、额外费用和预计送达；
- Agent 不读取/输入支付密码、验证码或生物识别；
- 支付平台最终确认由老人本人完成。

## 7. 陪伴聊天

支持日常问候、熟悉话题、故事、音乐交流、回忆和简单情绪安抚。回复应短、慢、耐心，不用连续长篇输出。出现持续消极、自伤或急性身体不适表达时，进入安全策略而不是只继续闲聊。

## 8. 日常提醒

类型：用药、复诊、饮水、吃饭、睡眠、测量、社区活动、快递、门窗、燃气、电器。

提醒卡片：

- “我已完成”
- “稍后提醒”
- “联系家人”

“未确认”不等同于“未服药”。提醒计划和执行记录存 Room。

“今日提醒”按以下稳定规则展示：

- 未完成和“稍后提醒”的卡片按事件发生/计划时间从早到晚排列；
- “我已完成”的卡片统一放到列表最下方，已完成组内仍按事件时间排列；
- 等待确认使用普通背景，“稍后提醒”使用强调色背景，已完成使用弱化背景和独立状态文字颜色，三种状态不能只靠文案区分；
- 家属即时通知以端侧收到并写入 Room 的时间作为事件时间，远程提醒以 `scheduled_at` 作为事件时间。

家属通知与远程提醒接入规则：

- 家属端“发送通知”和“创建提醒”已由占位入口改为可提交表单，所有内容必须先写入 FastAPI 中台；
- 老人端使用 device credential 在启动及进入本页时 REST 补拉；WebSocket 后续只作为触发补拉的提示；
- 通知收到后以“家人通知”加入当天列表，一次性提醒按服务端 UTC 时间转换为本地时间；
- 本地 Room 以 `command_id` 去重，写入成功后才 ACK，断网时仍可查看已保存提醒；
- 中台通知、提醒、补拉和 ACK 接口已实现并完成双端基础联通测试；Android 仍以 REST/Room 为事实来源，不把 WebSocket 在线提示当作送达结果。

## 9. 快捷联系与 SOS

联系页不再内置测试对象。它按关系显示中台同步的家属称呼、完整手机号和大号拨号按钮，点击后使用系统 `ACTION_DIAL` 打开拨号页。联系人完整快照先用 Android Keystore AES-GCM 加密保存在应用私有目录并排除云备份；离线时显示上次快照。中台待实现的设备专用接口见 [`../04-middle-server/elder-family-profile-sync-requirements.md`](../04-middle-server/elder-family-profile-sync-requirements.md)。

SOS 支持首页按钮、语音关键词和可配置硬件按键入口。

SOS 并行流程：

- 本地震动和语音确认；
- 短暂取消窗口；
- 本地拨打紧急联系人/进入 120 拨号流程；
- 尝试发送短信与位置；
- 同时向 FastAPI 创建 SOS 事件；
- 页面持续显示已执行步骤。

## 10. 跌倒检测接口

MVP 页面允许从相册/文件选择一张图像，发送给配置的 MLLM 图像分析接口，得到结构化结果：

```json
{
  "risk_level": "unknown|low|medium|high",
  "possible_fall": false,
  "person_visible": true,
  "needs_human_review": true,
  "summary": "..."
}
```

结果必须标注“AI 初步分析，不能替代人工确认”。不自动拨打急救电话。

## 11. 本地音乐

扫描用户授权的本地音乐文件；支持播放、暂停、上一首、下一首、音量、按名称搜索和定时关闭。无模型/网络时仍可用。

## 12. 新闻、天气与生活提醒

通过 Tool Provider 获取结构化数据，再由 Agent 用简短中文播报。新闻首版使用 Mock 或可配置公开源，不抓取未经授权内容。天气输出应包含行动建议，如带伞和加衣，而不是只读温度。

## 13. 家属模式 UI

- 老人列表/绑定页；
- 今日状态；
- 提醒确认时间线；
- 发送通知；
- 创建提醒；
- 模型用量；
- 紧急事件；
- 交易审批；
- 紧急联系人管理。

离线或最后状态过旧时必须显示“最后更新时间”，不能显示“当前正常”。

### 家属端基础 UI 骨架

- 顶部显示家属称呼和资料编辑入口；
- 连接卡片固定显示中台连接状态、绑定准备状态和最后同步时间；
- 老人资料卡只展示称呼、关系和绑定状态，不展示完整手机号；
- 今日状态、提醒记录、发送通知、创建提醒、模型用量和紧急事件已建立入口；
- 发送通知和创建提醒已接入中台命令 Repository 与表单；今日状态、提醒记录、模型用量等尚无对应接口的入口仍会明确提示“接口尚未进入当前开发阶段”。
